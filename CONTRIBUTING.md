# Contributing

Open an issue describing the observed behavior, expected behavior, software versions and a minimal reproduction using synthetic frames. Do not include names, student identifiers, contact information, private filesystem paths, participant images or raw EEG recordings.

Keep firmware, serial protocol and documentation consistent. Run the hardware-independent tests before proposing changes, and state whether real hardware was used. Report assistance flags for gameplay measurements. Changes to upstream-derived game code or sprites must address their license provenance.
